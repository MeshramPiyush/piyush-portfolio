# Piyush Meshram — Data Analyst Portfolio

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.

This is a responsive static portfolio website. It works without installing anything.

## Before publishing
- The project cards currently link to your GitHub profile because direct repository URLs were not listed in the resume. Replace each project link in `index.html` with its exact repository URL.
- Check that your phone number, email, LinkedIn, and GitHub links are correct.
- The resume PDF is included in `assets/`.

## Publish free
You can host this site with GitHub Pages:
1. Create a new GitHub repository (for example, `piyush-portfolio`).
2. Upload `index.html` and the `assets` folder.
3. In repository Settings → Pages, select deployment from the `main` branch and root folder.
4. GitHub will provide a public website URL after publishing.
